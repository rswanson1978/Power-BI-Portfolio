# Anesthesia Quality Improvement Dashboard

## Project Overview

This project demonstrates the development of an enterprise Power BI reporting solution designed to support anesthesia quality improvement and clinical analytics.

The dashboard integrates clinical data from multiple Epic Clarity domains and transforms complex patient-level, surgical, anesthesia, and quality data into actionable metrics for quality improvement initiatives.

All data and examples included in this portfolio are fictional, de-identified, or recreated. Proprietary institutional logic and protected health information (PHI) have been removed.

---

## Business Problem

Anesthesia quality improvement requires information from multiple areas of the electronic health record. Relevant data may exist across surgical encounters, anesthesia records, flowsheets, clinical documentation, and quality reporting systems.

The goal of this project was to integrate these data sources into a standardized analytical model and provide clinicians and quality teams with an interactive Power BI dashboard for monitoring anesthesia quality metrics.

---

## Solution

The reporting workflow was designed to move clinical data through several stages:

**Epic Clarity → PostgreSQL / SQL → Power Query → Power BI Semantic Model → DAX → Interactive Dashboard**

Key components included:

- Development of complex SQL queries across multiple Epic Clarity domains
- Integration of anesthesia, surgical, flowsheet, SmartData Element, and quality documentation
- Data transformation and validation using Power Query
- Development of a Power BI semantic model
- Creation of patient-level quality metrics
- Development of custom DAX measures
- Interactive filtering and visualization of quality outcomes
- Automated reporting workflows for ongoing quality monitoring

---

## Dashboard Features

The dashboard supports analysis of anesthesia quality metrics through:

- Patient-level and procedure-level reporting
- Clinical and operational quality measures
- Interactive filters and slicers
- Trend analysis
- Drill-down analysis
- Automated data refresh
- Standardized metric definitions
