# Power BI Portfolio

This repository contains selected Power BI projects demonstrating healthcare analytics, clinical informatics, quality improvement reporting, data integration, and enterprise dashboard development.

Projects demonstrate the complete analytics lifecycle, including SQL development, data transformation, semantic modeling, DAX, visualization design, and automated reporting.

All organization names, identifiers, proprietary business logic, and internal database structures have been generalized. All examples use fictional, de-identified, or recreated data. No protected health information is included.

## Featured Projects

|---|---|---|
| [Anesthesia Quality Improvement Dashboard](./01-anesthesia-quality-improvement/) | Enterprise anesthesia quality dashboard integrating clinical, surgical, anesthesia, flowsheet, and quality data. | Power BI semantic modeling, DAX, Power Query, Epic Clarity integration, clinical quality analytics |
| [AYA Cancer Dashboard](./02-aya-cancer-dashboard/) | Multi-institution oncology reporting solution integrating patient, diagnosis, treatment, survivorship, and primary care data. | Multi-source data integration, patient-level modeling, DAX, Power Query, cross-institution analytics |
